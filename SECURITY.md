# Security Policy

## Supported Versions

Como este proyecto es una solución MLOps de arquitectura abierta en constante evolución, la versión actual es la única que recibe parches activos de seguridad y actualizaciones de dependencias.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Si descubres una vulnerabilidad de seguridad relacionada con la API, la exposición de credenciales o los contenedores, por favor repórtala de forma responsable.

- **Dónde reportar:** No abras un *Issue* público en GitHub para vulnerabilidades sensibles. En su lugar, puedes enviar un correo directo o contactarme a través de mi perfil de GitHub [@seba39399](https://github.com/seba39399).
- **Qué incluir:** 
  - Una descripción detallada de la vulnerabilidad.
  - Pasos o prueba de concepto (PoC) para reproducir el fallo.
  - El impacto potencial del problema (ej. exposición de endpoints, fugas en variables de entorno, etc.).
- **Qué esperar:** 
  - Recibirás una respuesta de acuse de recibo en un plazo máximo de **48 horas**.
  - Si el reporte es validado y aceptado, se trabajará en un parche prioritario y se te dará el crédito correspondiente en las notas de la versión.
